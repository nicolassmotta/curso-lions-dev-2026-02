## Como rodar

Os arquivos que pedem entrada usam o `prompt-sync`. Instale as dependências uma
vez, na raiz do repositório:

```bash
npm install
```

Depois é só executar o arquivo que quiser:

```bash
node modulo02/resolucao_exercicios_slides/estruturas_decisao/par_impar.js
```

> O `package.json` da raiz tem `"type": "module"`, que é o que permite usar
> `import` no lugar de `require`.
